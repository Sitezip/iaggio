How to Use
Use Cases
Daily Driver — Keep home as a quick-launch pad for stops you visit every week.
Trip Planner — Name a view after your trip (e.g. nashville-2026), add all stops, then share the short link with travel companions.
Delivery Run — Add all drop-off addresses, toggle waypoints in order, hit Navigate for a live multi-stop route in Google Maps.
Field Teams — Each team member uses their own named view; a manager loads team-a||team-b to see everyone's sites at once.
Nested Lists — Create a regions view with cards for each city, then drill into regions--chicago for Chicago-specific stops.
Views
The view input in the header controls your active view — a named group of locations. The default home view saves data locally in your browser. Type any other secret name and press to switch to a cloud-synced view.
Adding a Location
Enter a Name and an Address or Plus Code, plus an optional short Note, then click Add. Use the Test button to open the address in Google Maps and verify it before saving. When you're signed in on a cloud view, a Visibility dropdown lets you save the location as Public or Private (see Accounts & Private Locations below). On cloud views, the Access toggle sets a public location to Editable (anyone with the view name can edit or delete it) or View-only, meaning anyone can see it and route to it, but once it's saved it's locked: only a site administrator can edit or delete it, and that includes you. Double-check the details before saving.
Navigating
Click Navigate on any card to open that location directly in Google Maps. If you have waypoints selected (see below), that location becomes the destination and the waypoints form the route in order. The button next to it just shows the location on the map, ignoring any waypoints.
Multi-Stop Routes
Click the circular toggle in the top-right of each card to add it as a waypoint. Cards are numbered in the order you select them. A route bar appears at the bottom showing the sequence. Hit Navigate on any card to set it as the destination and launch the full route in Google Maps. Click Clear in the route bar to reset.
Editing & Deleting
Each card has an Edit button to update its name, location, or note inline, and a Delete button — click it again within a few seconds to confirm. Deleted locations disappear from the view right away. Cards marked View-only show Locked instead: only a site administrator can edit or delete them, though a signed-in user can still make a private copy.
Searching
The filter bar above the cards searches across both location names and addresses in real time. Cards not matching the query are hidden until you clear the search.
Sharing a View
On any named view (not home), a short link is automatically generated near the top of the page. Click Copy to copy it to your clipboard and share it with others. To share just one location, use the button in a card's corner — it opens a read-only page for that single location, with its own short link. Anyone with the view name can see its public locations, so pick a name that's hard to guess.
Accounts & Private Locations
Click in the header to Sign In or Sign Up with an email and password; the icon changes to while you're signed in, and clicking it again lets you sign out. While signed in on a cloud view, the Add panel offers a Visibility choice: Private locations are visible only to your account (marked with a Private badge), while Public ones are visible to anyone with the view name. The Public / Private button on each card switches it: Move re-creates it with the new visibility and removes the original, while Copy adds a duplicate and keeps the original. Locations in home stay in your browser and are always private to this device.
Sub-Views
The button on each card opens a child view named after that card — the URL becomes ?v=parentview--childname. A breadcrumb at the top lets you navigate back up the hierarchy. This lets you organise locations as a tree: a regional view whose cards drill into city-level lists, a project view that fans out into site lists, and so on.
Multi-View
Separate two or more view names with || in the view input (e.g. office||warehouse) to load them side by side. Cards from every view appear together, each tagged with its source. A Save to View dropdown appears in the Add panel so you can choose which view a new location is added to.
Adding Stops by URL
Add a stop without using the form by opening an iaggio.com URL with name and address parameters, plus v for the view. Leave out v to add to home. The stop is saved as soon as the page loads, the two parameters are removed from the address bar, and a stop with the same name and address is never added twice. Stops added this way are always public. URL-encode each value: spaces become %20, commas %2C, and the + in a Plus Code must be %2B, or it's read as a space. Add to your home list (this browser only) https://iaggio.com/?name=Space%20Needle&address=400%20Broad%20St%2C%20Seattle%2C%20WA Add to a named cloud view https://iaggio.com/?v=nashville-2026&name=Ryman%20Auditorium&address=116%205th%20Ave%20N%2C%20Nashville%2C%20TN Add a Plus Code https://iaggio.com/?v=nashville-2026&name=Trailhead&address=8FW4V75Q%2B8Q Add to a sub-view https://iaggio.com/?v=regions--chicago&name=The%20Bean&address=201%20E%20Randolph%20St%2C%20Chicago%2C%20IL
Type a unique/secret name & press Enter to create your personal and sharable destination list!
